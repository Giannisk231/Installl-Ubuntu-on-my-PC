# Install Ubuntu on My PC

## Overview

This project documents my experience installing and configuring Ubuntu Linux on my personal computer.

The goal was to explore Linux as a daily operating system, learn system administration, and understand the process of setting up a complete Linux environment.

---

## Installation

The installation process included:

* Creating a bootable USB installer
* Configuring BIOS/UEFI settings
* Installing Ubuntu
* Setting up partitions
* Installing required drivers and updates

---

## Configuration

After installation, I configured:

* System updates
* Essential applications
* Development tools
* Network settings
* User preferences

---

## What I Learned

Through this project I learned:

* Linux installation process
* BIOS/UEFI boot options
* Disk partitioning
* Package management
* Terminal usage
* Linux system configuration
* Troubleshooting hardware compatibility
